# Roteiro de pitch — 3 minutos

Demo local da landing page Radiadores Vitória para reunião presencial.

## Antes da reunião

```bash
cd /home/tiago/Development/php/radiadores_vitoria
npm install
npm run build
npx serve . -p 3333
```

Abrir `http://localhost:3333` no notebook. Para mostrar no celular do cliente, conectar ambos na mesma rede Wi-Fi e acessar `http://SEU_IP:3333`.

---

## Roteiro (≈ 3 min)

### 1. O problema (30 s)

- Abrir o Google no celular/notebook
- Pesquisar: `Radiadores Vitória Porto Alegre`
- Mostrar que aparecem só diretórios genéricos (Página Amarela, Infoisinfo) — sem site próprio
- Frase-chave: *"Hoje, quem pesquisa sua empresa não encontra uma página profissional."*

### 2. A solução (60 s)

- Abrir a landing page local
- Rolar pelo hero: *"Assim seus clientes te veriam — profissional, confiável, com WhatsApp na hora"*
- Mostrar seções: Serviços → Galeria → Localização com mapa
- Clicar no botão WhatsApp e mostrar mensagem pré-preenchida
- Frase-chave: *"Um link único para colocar na bio do Instagram e em cartões de visita."*

### 3. Mobile (30 s)

- Abrir no celular do cliente (ou redimensionar o navegador)
- Mostrar botão flutuante do WhatsApp sempre visível
- Frase-chave: *"A maioria dos clientes pesquisa pelo celular — o site funciona perfeitamente."*

### 4. Proposta comercial (60 s)

Sugerir pacote:

| Item | Descrição |
|------|-----------|
| Site | Landing page profissional (como a demo) |
| Domínio | Ex.: `radiadoresvitoria.com.br` |
| Hospedagem | Servidor rápido e seguro |
| SEO local | Aparecer no Google para "radiador Porto Alegre" |
| Manutenção | Atualizações, fotos do Instagram, suporte mensal |

Frase de fechamento: *"Posso colocar isso no ar em poucos dias, com suas fotos reais e seus textos. Quer que eu prepare a proposta?"*

## Objeções comuns

| Objeção | Resposta |
|---------|----------|
| "Já tenho Instagram" | "O Instagram é ótimo, mas o Google não indexa bem. O site aparece nas buscas e centraliza tudo." |
| "Não preciso de site" | "Seus concorrentes já têm. Quem pesquisa hoje escolhe quem parece mais confiável." |
| "É caro?" | "Menos que um conserto de radiador — e traz clientes novos todo mês." |
| "Posso pensar?" | "Claro. Deixo a demo rodando — é só abrir o link no navegador." |
